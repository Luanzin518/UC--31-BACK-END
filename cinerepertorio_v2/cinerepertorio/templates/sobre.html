Sobre o CineRepertório

O projeto

O CineRepertório reúne filmes que funcionam como repertório sociocultural legitimado na redação do ENEM. Cada título traz sinopse, temas, nota do IMDb, indicação do parágrafo em que rende melhor, uma citação pronta em linguagem formal e links para assistir legalmente.

Hoje o catálogo tem {{ total }} filmes e {{ total_anotacoes }} anotação(ões) pessoal(is) salva(s).

Tecnologias

  • Python + Flask — rotas, formulários e regras da aplicação.
  • Jinja2 — herança de templates a partir de base.html.
  • Bootstrap 5 + CSS próprio — layout responsivo e tema escuro com dourado.
  • JavaScript — esteiras de cartazes e botão de copiar citação.
  • Arquivos JSON — persistência dos dados, sem banco de dados.

Acessibilidade

  • Link “pular para o conteúdo” e navegação completa por teclado com foco visível.
  • HTML semântico: header, nav, main, section, article, footer.
  • Textos alternativos em todos os cartazes e rótulos associados a cada campo de formulário.
  • Avisos do sistema anunciados por leitores de tela (aria-live).
  • Contraste alto entre texto e fundo; animações param no hover e no foco.
